# 研究资产库

把论文、原文和代码放在一起，方便查找、阅读和整理。

![按会议和年份查找论文](docs/images/library-desktop.png)

## 第一次使用

1. 打开 **研究资产库**。
2. 进入 **领域**，选择已有方向，或新建一个方向。
3. 点击 **添加论文**，选择 PDF，确认题名和所属领域。
4. 点击 **预览与重复检查**，核对后点击 **确认入库**。

只填题名并提供 PDF 就能开始使用，其他信息可以后补。

## 找论文

进入 **全部资料**，输入题名或关键词，点击 **搜索**。

也可以用领域、会议、年份和阅读状态缩小范围。例如，只看自己资料库中的 CVPR 2026 论文：

- 在 **会议 / 期刊** 中填写 `CVPR`。
- 在 **发表年份** 中填写 `2026`。
- 点击 **搜索**。

不需要的条件，点击下方筛选标签上的 **×** 清除。经常使用的条件可以保存成视图，下次从侧栏直接打开。

## 读原文、看代码

点击论文的 **打开资料**，进入详情：

- **PDF**：阅读原文、跳转页码、放大或缩小。再次打开时会恢复上次的阅读位置。
- **选择 PDF 版本**：有多个版本时，在列表中切换。
- **代码**：浏览这篇论文已关联的代码目录和文件。

有需要时，可以选中文字做高亮、写批注。没有提供的材料会显示为不可用。

## 整理阅读进度

- 用 **未读、阅读中、已读** 标记进度。
- 把相关论文加入同一个 **收藏集合**，按课题集中阅读。
- 选中多篇论文，可以批量调整状态或标签。
- 想比较论文，在卡片的 **更多** 中选择 **加入对比**，再点击 **打开对比**。
