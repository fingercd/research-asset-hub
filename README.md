# Research Asset Hub · 研究资产库

**论文、原文、代码和阅读笔记，放在一起才好用。**

研究资产库是一款 Windows 桌面应用，帮助你把散落的科研资料整理成随时能查、能读、能继续研究的个人资料库。从找到一篇论文，到打开原文、查看实现、记录想法，不必来回翻文件夹。

[安装与启动](#安装与启动) · [快速上手](#快速上手) · [使用手册](docs/USER_MANUAL.md) · [介绍海报](docs/images/research-asset-hub-poster.png)

## 为什么用它

### 不只是存 PDF，而是围绕论文组织资料

一篇论文的原文、不同版本、相关代码和阅读记录集中在同一个地方。找到论文后，可以顺着它读原文、看实现，而不是重新搜索一遍文件位置。

### 让查找更有针对性

按题名、关键词、研究领域、会议和年份筛选。想看自己库里的 CVPR 2026 论文，就分别选择会议和年份；经常使用的条件可以保存成视图，从侧栏一键进入。

### 读到哪，下次接着读

内置 PDF 阅读器支持版本切换、页码跳转、缩放、文字高亮和批注。再次打开时恢复阅读位置，长论文不用每次从第一页开始找。

### 论文与代码一起看

直接浏览已关联的代码目录和文件，区分本地代码与在线链接、官方实现与第三方复现。阅读方法时，能更快找到对应实现。

### 把阅读变成自己的研究积累

用未读、阅读中、已读管理进度；用收藏集合组织课题；批量调整状态和标签，或把多篇论文放在一起对比。领域总览和阅读路线也能帮助你了解一个方向。

### 也能让 AI 帮你查资料

支持把资料库接入 AI 客户端，用自然语言查论文、读取原文页码和代码位置，例如：“找几篇视觉语言导航中的压缩论文，给我原文与代码线索。”配置方法见[接入指南](docs/MCP_USER_GUIDE.md)。

## 安装与启动

**支持 Windows x64。当前版本为 0.3.0-rc.1，尚未发布可直接下载的公开安装包。** 下面区分已有程序和从源码运行两种情况，不把下载源码当成安装完成。

### 已经拿到桌面程序

- 如果拿到的是安装程序，运行安装程序后，从开始菜单打开 **研究资产库**。
- 如果拿到的是完整便携目录，保留其中所有文件，运行目录内的 `research-asset-hub-desktop.exe`。不要只复制一个 EXE。
- 第一次打开后，按下面的步骤建立领域并添加论文。

### 从源码运行

需要先准备 Python 3.11+、uv、Node.js 24、pnpm、PowerShell 7，以及 Rust 和 Windows C++ 构建工具。

```powershell
git clone https://github.com/fingercd/research-asset-hub.git
cd research-asset-hub
.\scripts\bootstrap.ps1
.\scripts\desktop.ps1 build
```

构建完成后，还需要准备配套运行文件，并指定一个新的资料目录才能启动：

```powershell
.\scripts\desktop.ps1 run `
  -RuntimeRoot 'D:\ResearchAssetHub\runtime' `
  -DataDir 'D:\ResearchLibrary'
```

上面的路径只是示例：`RuntimeRoot` 必须是已经准备好的运行文件目录，不能随意新建空文件夹代替；`DataDir` 建议使用新的专用目录。源码不包含你的论文，也不附带全部运行文件。首次配置请按[完整安装与运行指南](docs/DEVELOPMENT.md)操作；需要制作安装包时看[桌面构建说明](desktop/README.md)。

## 快速上手

1. **建立领域**：进入“领域”，选择已有方向，或新建一个研究方向。
2. **添加论文**：点击“添加论文”，选择 PDF、确认题名与所属领域，再完成“预览与重复检查”和“确认入库”。
3. **查找资料**：进入“全部资料”，输入关键词，或按会议、年份和阅读状态筛选。
4. **开始阅读**：点击“打开资料”，进入 PDF 或代码页签；有多个 PDF 时可选择版本。
5. **整理进度**：标记阅读状态、加入收藏集合、添加笔记；需要比较时，从卡片的“更多”中选择“加入对比”。

题名和 PDF 是添加论文的基本材料，其他信息可以后补。不需要的筛选，点击条件标签上的 **×** 清除。

## 常见问题

**需要把原来的文件全部搬进来吗？**

不需要。已有资料可以保留在原位置，按[现有资料加入指南](docs/USER_KNOWLEDGE_BASE_GUIDE.md)登记；新添加的 PDF 也可以由应用保存。

**没有代码或导读，能用吗？**

能。它们是选填材料，不影响先阅读 PDF。

**可以离线使用吗？**

已经保存在本机的 PDF 和代码可以离线阅读；在线链接和下载新材料仍需要网络。

**会自动帮我运行论文代码吗？**

不会。这里提供代码查阅和资料关联，运行实验仍需要自行准备环境、数据和权重。
