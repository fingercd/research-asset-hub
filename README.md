# Research Asset Hub · 研究资产库

**找论文，读原文，看代码。**

一个在 Windows 上使用的本地科研资料库。把论文 PDF、相关代码和阅读记录放在一起，少花时间翻文件夹，把精力留给研究。

## 可以用它做什么

### 找到需要的论文

按题名、关键词、研究领域、会议和年份查找已入库的资料。例如，查看 CVPR 2026 论文时，分别填写会议与年份，不必在一长串搜索结果中手动挑选。

常用条件可以保存成视图，从侧栏直接进入。列表适合快速浏览，详细卡片适合阅读摘要；切换显示方式不会丢掉筛选和已选论文。

### 在应用里读 PDF

打开本地原文，切换版本、跳转页码、缩放或适应窗口宽度。下次回来时，继续上次的阅读位置，不用重新翻到那一页。

支持文字高亮和批注。不同 PDF 版本分开处理，避免把旧版本的标记放到新文件上。

### 顺着论文看实现

从论文详情进入关联代码，浏览目录和源码。你可以区分本地代码、在线链接、官方实现与第三方复现，不必再靠文件夹名字猜对应关系。

### 整理自己的阅读工作

用“未读、阅读中、已读”记录进度，把相关论文放进专题集合，也可以批量调整状态和标签、对比多篇论文。研究领域页面提供总览与阅读路线，方便从一个方向开始系统阅读。

### 让 Agent 帮忙查资料

通过 MCP 这个连接接口，把资料库接入支持它的 AI 客户端，再用自然语言提问，例如：

> 找几篇视觉语言导航中的压缩论文，给我原文页码和相关代码位置。

Agent 可以检索资料、读取原文和代码，但这个接口不会修改资料库或运行论文代码。接入方法见 [MCP 指南](docs/MCP_USER_GUIDE.md)。

## 开始使用

### 已经有本机程序

1. 打开 **研究资产库**，在“领域”中选择或新建一个研究方向。
2. 点击 **添加论文**，选择 PDF 并确认题名。作者、会议和年份可以后补，HTML 与代码选填。
3. 回到 **全部资料**，搜索或筛选论文，打开 PDF 开始阅读。
4. 遇到值得继续研究的内容，加入集合、记录阅读状态或添加笔记。

已有一批 PDF 和代码，不想重新搬文件？可以按[批量加入现有资料](docs/USER_KNOWLEDGE_BASE_GUIDE.md)的说明登记原位置。

### 第一次获取程序

当前为 **0.3.0-rc.1 Windows 候选版本**，尚未发布公开安装包。这个仓库提供源码，不附带个人论文和数据库。

如果需要从源码运行，请看[开发与构建指南](docs/DEVELOPMENT.md)。日常使用已经配置好的桌面程序，不需要另外启动网站。

## 资料保存在什么地方

论文和阅读记录保存在本机。新增 PDF 可以交给应用保存；已经登记的外部文件保留在原位置，不会因为加入资料库就被移动或覆盖。本地已有的 PDF 和代码可以离线阅读，远程链接仍需要网络。

请为资料库做好备份。Git 只保存应用源码，不能替代论文和数据库备份；外部引用的原件也需要单独保护。具体操作见[使用手册](docs/USER_MANUAL.md)。

## 常见问题

**下载源码，就能得到里面的全部论文吗？**

不能。应用源码和个人资料分开保存，你需要添加自己的资料，或接入已有的本地资料目录。

**只有 PDF，没有代码或导读，可以加入吗？**

可以。论文题名和 PDF 必填，其他材料选填。

**搜索结果能直接当作论文结论吗？**

不能。搜索用于找到候选资料，具体结论仍应回到原文核对。会议和年份来自库内记录，也不代表官方会议全集。

**关联了代码，就能一键复现实验吗？**

不一定。代码浏览不等于环境、数据集和权重已经齐备；应用不会自动执行下载的代码。
