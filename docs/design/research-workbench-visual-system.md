# Research Asset Hub · 清晰桌面工作台视觉规范

更新：2026-10-28，0.3.0-rc.1。以实际 [styles.css](../../apps/web/src/styles.css)、[目录样式](../../apps/web/src/styles/catalog-workspace.css)及[阅读样式](../../apps/web/src/styles/reading-workspace.css)为实现依据，不再沿用暖色展示页的大标题与装饰性渐变。

## 方向

**优先让用户看清题名、条件、材料状态和下一步操作。** 白色内容区、浅冷灰背景、深色文字与单一低饱和 teal 强调色形成层级；不用大阴影和重复卡片边框制造主次。保留本地桌面风格，不引入外部字体下载或新组件框架。

旧[视觉参考图](research-workbench-visual-direction.png)仅保留为历史，不是现行配色和尺寸的验收标准。产品流程取舍见[资料工作台设计](desktop-library-workbench.md)。

## 核心颜色与字体

| 用途 | 当前值 |
| --- | --- |
| 工作区 / 内容表面 | `#f2f5f7` / `#ffffff` |
| 主文字 / 辅助文字 | `#1f2933` / `#536473` |
| 边界 / 强边界 | `#d8e0e5` / `#b9c6cf` |
| 主强调 / 深强调 / 浅强调 | `#236b79` / `#195663` / `#e2f0f2` |

UI 字体优先 Segoe UI、Microsoft YaHei UI，随后使用系统无衬线回退。PDF 正文仍按论文自己的字体渲染，不为统一 UI 字体改动原文或文字层几何。

仅对核心 token 对的离线计算：主文字/白底 14.76:1、辅助文字/白底 6.11:1、次要文字/白底 5.02:1、深强调/浅强调 7.04:1、白字/主按钮 6.09:1。这不是整页、全部状态或辅助技术的完整无障碍审计。

## 布局与层级

- 普通页面标题 25–30px，详情标题 23–28px；领域门户主标题 30–34px、章节 22–26px，不再放大到 64/42px。
- 普通页面内边距从 48×56px 收紧到 24×32px；首页主区从 34×38px 收紧到 20×22px。
- 主搜索控件高度从 58px 收紧到 42px；常用筛选在首层，高级条件按需展开，当前条件单独显示。
- 常规按钮 36px、紧凑动作更小，控件标签与禁用状态明确；不为密度把全部内容压成不可读的小字。
- 内容卡片使用清楚细边框和小圆角；常规阴影只辅助浮层，不承担阅读区层级。
- 侧栏分开“功能入口、资料视图、保存视图”，选中态与分组标题不能仅靠细微色差区分。
- PDF 白纸与浅灰工具条分开；页码、版本和缩放属于同一阅读工作区，不用装饰遮挡正文。

## 交互与验收

- 紧凑/详细切换不改变数据、选择与查询；主操作和 PDF/HTML/代码材料操作保持各自位置。
- 键盘焦点使用可见外环；状态同时有文字，不只依靠颜色。保留 reduced-motion 支持。
- 桌面原生窗口检查首页、检索、领域总览、详情/PDF和设置；按真实窗口尺寸记录首屏、截断和横滚，不拿不同尺寸截图声称同尺度提升。
- 构建和组件测试证明逻辑未退化，不能替代真实 WebView 中的显示检查。最新原生证据与未覆盖范围见[改革报告](../reports/2026-10-28-desktop-product-reform.md)。
