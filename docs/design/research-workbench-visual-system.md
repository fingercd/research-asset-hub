# Research Asset Hub 视觉系统

## 方向

界面采用 **Quiet Research / 安静的编辑部式工作台**：它首先是一张适合阅读与检索的数字书桌，其次才是管理后台。视觉焦点始终落在“搜索—继续阅读—打开资料”这条主路径上。

参考稿：[`research-workbench-visual-direction.png`](./research-workbench-visual-direction.png)

## 设计原则

1. 一级导航只保留“资料库、领域、笔记”，任务、冲突和设置统一收进系统状态抽屉。
2. 首页只保留一个搜索入口；卡片默认最多暴露两个直接操作，其余操作放入“更多”。
3. 用留白、字号和表面层级建立主次，避免白色卡片层层嵌套。
4. 中文正文不小于 13px，关键控件高度不小于 40px，移动端点击目标不小于 44px。
5. 图谱页面必须先说明当前仓库、索引状态和下一步操作，再展示画布。

圆角只使用 `8 / 12 / 16 / 22px`；间距遵循 `4px` 基线；普通阴影为 `0 12px 36px rgb(38 54 46 / 8%)`，弹层阴影为 `0 24px 72px rgb(25 36 31 / 18%)`。

## 字体层级

- 页面标题：`clamp(30px, 3vw, 42px) / 1.12 / 700`
- 区块标题：`20px / 28px / 700`
- 卡片标题：`16px / 24px / 650`
- 正文：`14px / 22px / 400`
- 辅助正文：`13px / 20px / 400`
- 标签与元数据：`12px / 18px / 600`

## 交互

- 普通反馈 `140ms`，状态切换 `180ms`，弹层 `240ms`，统一使用 `cubic-bezier(.2,.8,.2,1)`。
- 卡片悬停只上移 `1px`，不使用夸张缩放。
- 所有键盘焦点使用 3px 蓝色外环；状态不能只用颜色表达。
- `prefers-reduced-motion` 下关闭 transition、animation、transform 和平滑滚动。

## 响应式

- `> 1100px`：216px 侧栏，正文双列，概览侧栏可 sticky。
- `821–1100px`：正文单列，概览移到主内容之后。
- `<= 820px`：侧栏变为抽屉，显示 58px 移动端顶栏。
- `<= 620px`：页面左右 16px；搜索按钮只保留必要文案；卡片与筛选单列。

## 验收基线

- 资料库首页同一视口内只出现一个搜索框。
- 主导航恰好三个入口，系统工具仍可在系统状态抽屉访问。
- 搜索首层只显示领域、类型、阅读状态；其他条件进入“更多筛选”。
- 论文可加入对比，仓库不可加入对比。
- 关系图和代码图均能明确区分“未选择、未索引、名称冲突、服务不可用、可浏览”状态。
- 1440×900、1024×768、390×844 三个视口无横向溢出，键盘可完成核心操作。
