# VLN 论文统一导读 HTML v1

## 目标与边界

- 覆盖 Hub 中 `vision-language-navigation` 的 109 篇非无人机论文；31 篇 UAV、航空机器人、无人机或四旋翼导航论文按用户范围要求永久删除。
- 原 PDF、旧 HTML、旧 Markdown 与代码目录保持只读；新页面写入独立永久资料目录，并通过新旁车来源登记。
- 页面在桌面壳内离线可读，不把 CSS、字体、脚本、图片或正文托管到外部网站。
- 视觉语言统一，但内容结构允许随论文类型变化；综述、方法、基准、数据集和系统论文不强行套同一套论证顺序。
- 所有结论都能追溯到 PDF、现有导读或正式元数据；抽取不到时明确写“正文未核验到”，不补造数字。

## 内容来源优先级

1. PDF 正文、表格和结论页是事实主来源。
2. 已有中文分析 Markdown 用于复用经过人工整理的通俗表述，但要与 PDF 抽取结果交叉检查。
3. 已有 HTML 用于保留有效的结构和说明，不继承外链脚本、失效相对链接或旧样式。
4. 数据库元数据用于题名、作者、年份、会议信息、arXiv/DOI、代码和 Checkpoint 状态。

## 页面必须回答的问题

每篇页面至少包含以下语义区块；标题可按内容调整，顺序也可在不损害理解时变化。

1. **一分钟看懂**：用 2–4 句说明论文想解决什么、核心办法和最重要结论。
2. **问题为什么难**：说明输入、输出、环境和现有方法的具体瓶颈。
3. **方法怎么工作**：使用 3–6 个步骤或模块，不堆缩写；首次出现的缩写必须解释。
4. **证据是否支持**：列出数据集、指标、关键结果与 PDF 页码；不同设置不可直接横比。
5. **适用范围与局限**：区分作者明确承认的限制和导读者根据实验范围作出的保守判断。
6. **术语速查**：仅保留理解本文所需术语。
7. **来源与抽取说明**：列出 arXiv/DOI、页数、抽取器、缓存摘要和保真限制。

综述论文可将“方法怎么工作”换成“分类框架”；基准或数据集论文可换成“数据如何构建、如何评测”；系统论文可换成“组件与运行流程”。

## 通俗化规则

- 先给直观结论，再给形式化细节；每段只承担一个信息任务。
- 用“观察—判断—动作”“记住什么、何时忘掉”等具体语言解释抽象模块。
- 指标第一次出现写出中文含义，例如 `SR（成功率）`、`SPL（兼顾成功与路径效率）`。
- 不使用“显著提升”“全面领先”等空泛词；必须同时说明相对谁、在哪个数据集和哪个设置。
- 原文只给定性结论时，不从图表视觉估算数字。
- 英文原句只作为折叠证据摘录，中文正文必须能独立阅读。
- 无法可靠翻译或抽取的公式保留公式编号、所在页和解释性上下文，并标注需对照 PDF。

## 统一视觉系统

- 单文件、自包含 HTML；UTF-8、`lang="zh-CN"`、无 JavaScript。
- 背景使用暖白，正文墨黑，主色使用深绿；信息、证据、限制分别使用稳定的蓝、绿、琥珀语义色。
- 正文最大宽度 1120 px，阅读列 72–78 个中文字符；桌面双栏，窄屏自动单栏。
- 标题、卡片、表格、术语、证据定位和状态徽标共用同一组 CSS 变量与组件类。
- 页面可打印，打印时隐藏目录导航并保持表格、代码与链接可辨识。

## 可访问性与离线约束

- 使用 `header`、`nav`、`main`、`article`、`section`、`aside`、`footer` 语义标签。
- 必须有“跳到正文”链接；所有 `section` 都有唯一标题和稳定锚点。
- 颜色不作为唯一信息载体；正文对比度至少 4.5:1。
- 表格包含 `caption`、`thead` 和列标题；超宽表格放进可横向滚动容器。
- 外部链接使用正常 `https://` 导航并明确标注“联网”；本地 PDF 由 Hub 的 PDF 动作打开，页面内不写逃逸相对路径。
- 禁止外部字体、CDN、远程图片、内联事件处理器、表单和 iframe。

## 质量门禁

- 数量：109 个唯一 paper asset，109 个本地 PDF，109 个最终 HTML。
- 结构：DOCTYPE、标题、视口、主内容、跳转链接、至少 5 个语义区块齐全。
- 链接：内部锚点均有目标；无 `../`、盘符、`file://`、`localhost`、CDN 或远程主动资源。
- 内容：题名、作者、年份与数据库一致；PDF 页数大于 0；关键结果必须附页码或明确“摘要声明”。
- 运行：静态审计 109/109，无丢失本地依赖；浏览器桌面、390 px 与 320 px 全量无横向页面溢出、控制台错误；桌面及 390 px 全量可访问性检查无严重或关键违规。真实网关报告保留所有级别的违规计数，不把阻断阈值通过表述为全级别零违规。
- 导入：新来源全量 dry-run 通过；两次正式导入之间输入冻结，第二次所有新增计数为 0。

## 本地抽取器与保真限制

遵循用户 2026-09-12 的后续要求，不安装或使用 MinerU。使用现有 `pdftotext -layout` 提取版面文本、`pdfplumber` 定位表格、`pypdf` 校验页数与元数据，统一标记为 `local-layout`。数学公式、复杂双栏表格和字体编码可能需要人工对照原 PDF；页面与批处理报告明确说明这些限制。缓存必须绑定 PDF SHA-256、实际读取的旧文档 SHA-256 与抽取版本，不得把本地抽取描述为 MinerU 结果。

## 来源登记与默认入口

- 本批只读来源为 `vln-unified-guides-non-uav-20260912-v1`，稳定记录键使用 `guide-<原论文 asset UUID>`；通过现有 DOI/arXiv 与逐项审阅的弱身份集合合并，不创建重复论文。
- 新表示使用 `type=html`、`role=guide`，表示元数据标记 `unified_guide=true`、`sandbox_policy=static`。研究单元的 HTML 按钮和详情页的“导读”标签优先选择可用的统一导读；旧 HTML、Markdown 与 PDF 不被覆盖，详情页“原始 HTML”仍保留原入口。
- 内容须经逐篇 PDF 对照复核，记录 PDF SHA-256、实际读取的旧文档与核验说明；没有完整 authored 内容或 review 的条目不得自动补成套话页面。
- 正式登记后，来源目录和 manifest 冻结；后续修订使用新的版本目录与来源，不原位重写本批 HTML。
