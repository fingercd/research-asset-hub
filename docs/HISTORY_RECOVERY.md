## 为什么有些 SHA 与原来不同

Git 提交的 SHA 与文件内容和父提交有关。旧历史中剥离了个人资料登记、冻结导入证据、私人验收报告及受限第三方摘录，并将个人路径和私人邮箱脱敏，因此受影响的旧提交和后续提交会得到新的 SHA。

这不是把历史重新压成一个快照。原提交与新提交是一对一关系，完整对照见 [commit-map.json](history/commit-map.json)。原始 SHA、文件、标签及签名仍保存在本地原始备份中；清理后的提交不能沿用原始签名的验证结论。
