# 公共源码分发边界

[项目首页](../README.md) · [开发指南](DEVELOPMENT.md) · [空库配置](../config/README.md)

## 完整应用，不附送个人资料库

公共源码保留 Python API、文件网关、后台抽取、MCP、Tauri 桌面壳、React UI、数据库迁移、开发脚本、工具箱、依赖锁文件和全部原有测试代码。它不是只有前端的展示壳，也不需要开发者的个人论文目录才能建立新库。

首个公共快照的应用来源版本是 `3a7701fbe0e8b3931ab97abf1266ebaf7755bdfd`。公共仓库采用独立历史：私人来源登记、冻结导入证据以及第三方受限摘录不属于软件分发内容，原有证据不会被修改或删除。

## 不分发的内容

- 个人 `config/intake/` 来源快照、领域门户资产绑定、身份审批和研究评测标签；
- 个人来源根、本机路径、资料导出清单和日期化资料验收报告；
- 原论文 PDF、完整第三方代码、模型权重、数据集、数据库、认证缓存或运行日志；
- 无再分发授权的第三方文本、实现片段和附件。

公共 `config/` 使用空来源、空领域及空门户索引；弱身份合并审批也显式为空，而不是删除校验逻辑。安装包同样使用 `newconfig/release-defaults/`。所有已正式导入的用户来源仍遵守只读、哈希冻结和审计更正约束。

## 测试与可重复验证

普通 Python 单元测试、API/导入/网关/备份/MCP 的隔离测试、桌面 UI 和 Rust 测试保留。门户缓存与领域别名测试使用 `tests/fixtures/public_catalog/` 的小型测试数据；门户文字和资产 ID 是合成内容，不代表研究结论。

仅用于核验某个既有个人资料库的数量、冻结标签和来源绑定的测试，显式依赖 `local_research_assets` fixture；公共空库会报告跳过原因。它们不是被删除的产品功能测试，也不能被算成公开用户已经验证的论文覆盖率。完整运行方法见开发指南与 CI。

源码测试通过不等于安装、升级、卸载或在线目录全部材料的验收通过；各自的验证范围必须独立报告。
