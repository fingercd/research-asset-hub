# Research Asset Hub 用户使用手册

Research Asset Hub 是在本机运行的科研资料工作台，Windows 桌面版是主要入口，Web 版共用同一界面。普通论文可在“添加论文”中上传，领域可在界面新建和编辑；来源维护、索引重建、外部同步和备份仍有命令行或 API 操作。文档描述当前源码功能，已安装版本以实际安装包为准。

## 1. 启动与进入网站

在 PowerShell 中：

```powershell
cd "D:\ResearchLibrary\research-asset-hub"
./scripts/hub.ps1 start
./scripts/hub.ps1 status
```

打开：

- 网站：<http://127.0.0.1:8765>
- API 文档：<http://127.0.0.1:8767/docs>
- API 健康检查：<http://127.0.0.1:8767/api/health>
- 资产网关健康检查：<http://127.0.0.1:8766/health>

左下角和右上角的状态徽标每 30 秒检查一次：

- **系统就绪**：API 和依赖正常；
- **部分服务不可用**：网站能打开，但搜索、数据库或其他依赖有降级；
- **API 离线**：先检查 `hub.ps1 status`，必要时重新启动。

停止：

```powershell
./scripts/hub.ps1 stop
```

普通停止不会删除数据库和索引。不要手工执行带 `--volumes` 的 Compose 删除命令。

### WSL 与内存提示

本机没有原生 Docker CLI 时，启动脚本会为 PostgreSQL/Meilisearch 启动一个
Ubuntu WSL keepalive。日常启动不会重建索引，代码索引默认关闭；项目级容器上限为
PostgreSQL 768 MB、Meilisearch 1.5 GB。全量索引、备份或恢复演练属于一次性维护任务，
可能因 Linux 文件缓存短暂提高 `vmmemWSL`，不代表日常占用。停止脚本会关闭应用、容器
和 keepalive；若 WSL 仍短暂驻留且没有其他 WSL 工作，可手动执行 `wsl --shutdown`。

## 2. 全局导航与快捷操作

左侧导航分为：

- 主导航：资料库、添加论文、领域、收藏集合、笔记；
- 系统状态入口：后台任务、同步冲突、设置等维护页面。论文对比可从已选论文托盘进入。

在任何页面按 `Ctrl+K`，可搜索题名、作者、DOI/arXiv、仓库、导读或批注。输入后按 Enter 进入跨领域搜索；按 Esc 关闭。资产 UUID 目前不是可靠的全文检索字段，应从已有详情链接进入。macOS 对应 `Cmd+K`。

手机或窄屏使用左上角菜单按钮打开导航。

在论文卡片或详情页点击“加入对比”后，底部出现比较托盘：

- 最多加入 4 篇；
- 点击“打开对比”进入论文对比页；
- 点击关闭按钮可清空当前选择；
- 当前选择保存在浏览器 `localStorage`，普通刷新和路由切换会保留；清理浏览器站点数据后会丢失。

未知地址会进入 `/404` 页面。

## 3. 推荐的日常工作流

### 查找、阅读和记录

1. 按 `Ctrl+K` 输入题名、作者、DOI、arXiv、方法名或代码符号。
2. 在结果卡直接点 PDF、代码、导读或原始 HTML；也可点标题进入详情。
3. 把阅读状态改为“阅读中”。
4. 在详情页添加总结、问题、摘录、评论或一般笔记。
5. 阅读完成后改为“已读”。

以后再次搜索时，卡片会显示你的批注摘要；没有批注显示“无”。

### 比较多篇论文

1. 从搜索结果加入 2–4 篇论文。
2. 打开“论文对比”。
3. 并排查看研究问题、方法、贡献、实验、限制、代码、批注和关系。
4. 保存比较视图，或导出 Markdown。

### 查看资产关联

1. 在资产详情切换到“关系”标签。
2. 查看论文、代码和其他资产之间已经登记的关联证据。
3. 点击关联资产标题进入对应详情页。

## 4. 总览

地址：<http://127.0.0.1:8765/>

可以看到：

- 资产与论文总数；
- 未读、阅读中、已读数量；
- 领域、关系和批注统计；
- 最近资产或继续阅读；
- 从 API 动态生成的全部领域入口，以及每个领域的论文、仓库、研究单元和整体 HTML 可用状态；
- 索引未完成提示或空库引导。

可执行操作：

- 顶部搜索框进入全库搜索；
- 点击资产标题进入详情；
- 直接修改阅读状态；
- 点击领域进入该领域；
- “查看全部”进入搜索；
- 空库引导中的“查看导入任务”可跳到后台任务页。

领域卡由当前资料库动态生成，并非前端写死的枚举。新增领域后，领域目录会出现对应入口；个人库中的历史领域数量不代表新安装的默认内容。

索引状态提示本身只展示状态和说明，没有跳转按钮。总览数字来自当前数据库，会随着你新增资料而变化；README 中的数字只是注明日期的已验证登记基线。

点击“添加论文”即可上传 PDF 并预览入库。复杂来源导入与索引维护见 [自行增加知识库指南](USER_KNOWLEDGE_BASE_GUIDE.md)。

## 5. 跨领域搜索

地址：<http://127.0.0.1:8765/search>

### 两种模式

| 模式 | 适合 |
| --- | --- |
| 精确 | DOI、arXiv、完整题名、作者、仓库名和代码符号 |
| 关键词 | 默认模式，使用 Meilisearch 全文检索、模糊匹配和精确术语命中 |

搜索完全在本机 Meilisearch 关键词索引上执行，不加载本地模型，也不需要 GPU。关键词模式适合普通概念查询，精确模式适合 DOI、arXiv、完整题名、作者、仓库名和代码符号。

### 筛选

基础筛选：

- 领域；
- 阅读状态：未读、阅读中、已读；
- 类型：论文、代码仓库、数据集。

“更多筛选”：

- 作者或机构；
- 单个标签；
- 起始和结束年份；
- 是否有 PDF；
- 是否有代码；
- 是否有导读；
- 是否有 HTML；
- 是否有批注。

填写高级筛选后点击“应用更多筛选”。“清除更多筛选”只清理高级条件。

### 结果卡

网站默认把论文和已确认的 `implemented_by` 代码仓库合成一个“研究单元”：论文是主卡，仓库关键词命中时仍回到对应论文卡，并标注“命中关联代码”。没有已确认论文关系的仓库继续作为独立仓库卡；把类型切换为“代码仓库”时会查看原始仓库清单。

每张卡可：

- 点标题进入资产详情；
- 修改阅读状态；
- 加入论文对比；
- 按 `PDF / HTML / 导读 / 代码` 的固定顺序快速打开论文文件及关联仓库；
- 查看约 60 字批注摘要；
- 查看命中来源、必要时的排序分数和领域。排序分数不是匹配概率。

搜索卡上的按钮灰色表示该研究单元没有可用的对应表示；PDF 会进一步区分“来源未提供”和“已登记但文件缺失/来源受限”。按钮上的 `+N` 表示有多个可用入口，展开后可选择具体版本。不可用表示不会发送打开请求。结果较多时点击“加载更多”继续。

搜索无结果时，先使用“关键词”模式，减少筛选条件，再尝试更宽泛的中文或英文关键词。

## 6. 资产详情

地址格式：

`http://127.0.0.1:8765/assets/<asset-id>`

首屏展示题名、作者、年份、venue、领域、标签、阅读状态和快捷打开按钮。

### 概览

- 阅读摘要和结构化元数据；
- 查看已有批注；
- 新增批注；
- 查看全部表示；
- 切换到“关系”标签，再从该标签打开完整图谱；

### PDF

- 使用 PDF.js 在页面内显示；
- 使用“上一页”“下一页”翻页；
- 显示当前页码；
- 已成功取得 PDF 地址但页面解析/嵌入失败时，可“在新窗口打开”；安全会话创建失败时没有该回退按钮。

当前 PDF 面板没有全文搜索、缩放或下载工具栏；需要这些能力时在新窗口用浏览器/PDF 阅读器打开。

### 代码

- 本地代码或 Notebook 在隔离查看区域打开；
- 外部仓库 URL 在新标签页打开；
- 平台不会执行仓库中的代码。

如果你希望在编辑器中运行代码，应从登记的本地目录自行打开，并先审查安全性。

### 导读

- Markdown 使用安全渲染；
- HTML 导读通过隔离资产网关打开；
- Markdown 内容加载或渲染失败时通常回退到 iframe；安全会话创建失败时只显示错误。

### 关系

- 显示邻居数和关系边；
- 可以进入完整图谱；
- 关系真源来自 PostgreSQL。

### 相似论文

- 打开标签后才加载；
- 依赖本地 Meilisearch 关键词索引，不加载向量模型；
- 点击结果进入对应详情。

### 原始 HTML

原页面不会被重写。本地 HTML 通过独立 `127.0.0.1:8766` origin 打开，并按登记策略限制脚本、联网和资源访问；只登记了外部 URL 的 HTML 会直接在外部网站新标签打开，不经过本地网关。

- 静态：适合纯展示页面；
- 可信本地交互：允许经过审计的本地脚本；
- 需要联网：明确提示外部依赖。

旧页面缺少本地 JS、CSS 或图片时可能不完整；需要通过 `scripts/audit_html.py` 生成的 CLI 报告确认缺失依赖。

### 批注

可选择：

- 评论；
- 总结；
- 问题；
- 摘录；
- 一般笔记。

标题可选，正文必填并支持 Markdown。提交后会刷新当前资产的批注。

论文详情提供“编辑元数据”，可修改题名、中文题名、副标题、作者、年份、会议/期刊、语言、标签、来源链接、摘要及简介。保存失败保留输入；发生版本冲突时先读取最新值、核对后再保存。DOI/arXiv 属于身份标识，需通过身份更正流程处理；普通编辑不改写来源清单和文件。当前没有删除资产的图形按钮。

快捷按钮以及 PDF、代码、导读、原始 HTML 标签会选择该类型的可用表示；“全部表示”列表可以看到其他同类文件。详情批注列表显示已加载数量，并支持加载更多；PDF 页码锚点仍可跳回对应页面。

## 7. 领域

领域列表：<http://127.0.0.1:8765/domains>

每个领域显示：

- 名称和 slug；
- 论文主口径，以及单独列示的代码仓库和聚合研究单元数量；
- 阅读进度统计；
- “总览可用”“总览需联网”“总览缺失”或“暂无总览”状态。

点击领域进入 `/domains/<slug>` 后，默认打开“领域总览”。领域总览是 Hub 原生的完整页面，不在 iframe 或卡片中显示，也没有第二层滚动条。标题、论文/仓库/研究单元/阅读中统计以及四个视图切换都是总览页面自身的一部分。

所有领域都使用相同的九段目录，内容则来自各领域自己的资料：

1. 领域定位与边界；
2. 论文、代码与导读目录；
3. 发展时间线；
4. 能力与方法版图；
5. 代表工作与技术路线；
6. 任务、数据集与评测；
7. 推荐阅读路线；
8. 前沿趋势与开放问题；
9. 证据、来源与版本说明。

页头和“统计”视图都以 `paper_count` 作为论文总数。代码仓库数量是独立的开源/实现资产统计，全部资产数量还可能包含导读、HTML 等表示，二者都不能当作论文数或与论文数相加。研究单元是“论文及其关联代码”的聚合浏览口径；当它与论文数相同时，表示当前每篇论文恰好对应一个聚合单元，并不代表又多出同等数量的论文。

右上角“原始 HTML”是次级核对入口。只有数据库中登记的原始领域 HTML 状态为可用或需联网时按钮才可点击；点击后通过 `127.0.0.1:8766` 的隔离资产网关在新窗口打开。原始文件始终只读，Hub 的统一页面不会覆盖或改写它。若原始 HTML 缺失，统一页面和研究单元目录仍然可用。

领域详情还有三个标签：

- “研究单元”：完整聚合目录，首批加载 30 个研究单元；点击“加载更多”可继续浏览，页面显示“已加载 X 个研究单元，覆盖 Y / 总资产数”，共享仓库不会重复计数；
- “最近更新”：只展示最近 5 项；
- “统计”：首先显示论文主口径，再单独显示全部资产、仓库、聚合研究单元、阅读状态和批注数量。

右上角“搜索此领域”可在空关键词下直接浏览，也可继续增加关键词和筛选。

领域来自配置、托管领域和导入数据。领域页面支持新建与编辑名称、简介；当前没有删除领域按钮。

## 8. 论文对比

地址：<http://127.0.0.1:8765/compare>

使用方法：

1. 从搜索/详情加入论文，或在本页搜索论文。
2. 选择 2–4 篇。
3. 点击“保存并生成对比”。
4. 查看并排表格。

比较字段包括：

- 标题、作者、年份、venue；
- 研究问题；
- 方法/机制；
- 主要贡献；
- 实验；
- 限制；
- 代码；
- 个人批注；
- 关系；
- 领域和标签。

缺少的字段显示“无”，不会由 AI 自动臆造。

“导出 Markdown”会由浏览器下载本地 `.md` 文件。“已保存比较”可以重新打开。当前没有删除或编辑已保存比较的按钮。

已保存比较列表返回全部已保存视图；代码列与导出会纳入论文正式关联的代码入口，并区分本地可读、需联网和不可用情况。

## 9. 批注中心

地址：<http://127.0.0.1:8765/annotations>

可以：

- 按标题、摘要、正文或资产 UUID 在当前列表中筛选；
- 打开批注对应的资产；
- 编辑标题和正文；
- 保存或取消编辑；
- 删除批注；
- 新建批注。

全局新建需要手工填写资产 UUID。更方便的方法是在资产详情页直接添加，系统会自动绑定资产。

更新使用版本校验；如果其他页面已经修改同一批注，保存可能提示版本冲突，刷新后再处理。

点击“加载更多”可继续查看后续批注；页面筛选针对已加载内容，并显示已加载范围。删除失败会显示原因；版本冲突时先刷新当前批注，核对后再次确认删除。

## 10. 后台任务

地址：<http://127.0.0.1:8765/jobs>

显示：

- 等待中、运行中、成功、失败、取消；
- 进度和时间；
- API 返回的任务错误信息。

有进行中任务时约每 5 秒刷新，否则约每 20 秒刷新。也可手动点击“刷新”。

可操作：

- 失败任务：重试；
- 等待中或运行中任务：取消。

当前页面不能创建导入、抽取或索引任务。新增任务由命令行、API 或同步流程创建。

任务列表支持加载更多，手动刷新和自动刷新覆盖已加载页面。运行中的任务取消后需要等待执行方收尾；若执行方中断，后台会在租约过期后将取消任务收敛到取消状态。

## 11. 同步冲突

地址：<http://127.0.0.1:8765/conflicts>

Obsidian 等外部同步发生同字段冲突或“删除对编辑”时，冲突会出现在这里。页面展示 Hub 值和外部值，可选择：

- 保留本地；
- 采用来源；
- 合并。

处理结果会被审计，不会直接改写只读来源目录。当前没有批量解决或“重新同步”按钮；同步仍通过命令行执行。

冲突列表只展示待处理冲突，支持加载更多。解决后应用所选字段并更新合并基准；若内容自冲突产生后已经变化，会要求重新核对，避免覆盖新编辑。

## 12. 设置

地址：<http://127.0.0.1:8765/settings>

页面提供资料库位置与 MCP 配置入口，并展示：

- 应用与端口；
- 本地关键词搜索后端与降级状态；
- 来源适配器、状态和只读属性；
- Obsidian/Zotero 等集成状态。

桌面“资料库位置”可以选择空目录或已有兼容资料库，确认后切换并重启；浏览器只展示当前目录。“MCP 接入”可以复制配置并检查连接。其余状态卡片只读，secret、token、password、API key 和 credential 等敏感字段会被脱敏。备份通过维护脚本/API 执行，设置页没有备份按钮。

## 13. 网站外的管理操作

### 增加资料

见 [自行增加知识库指南](USER_KNOWLEDGE_BASE_GUIDE.md)。

### Obsidian

```powershell
./.venv/Scripts/python.exe scripts/sync_obsidian.py --preview-only
./.venv/Scripts/python.exe scripts/sync_obsidian.py
```

先预览，再应用。冲突到网站“同步冲突”页处理。

### Zotero

```powershell
./.venv/Scripts/python.exe scripts/export_zotero.py
```

在 Zotero 安装 Better BibTeX 后，人工导入：

- `outputs/zotero/research-assets.csl.json`
- 或 `outputs/zotero/research-assets.bib`

平台不会直接修改 Zotero SQLite。

### 开放目录

```powershell
./.venv/Scripts/python.exe scripts/export_catalog.py
```

输出位于 `outputs/open-catalog/`，包含 JSONL、Markdown、RO-Crate、关系和溯源，不复制来源 PDF 或代码目录。

### 备份

```powershell
./.venv/Scripts/python.exe scripts/create_backup.py `
  --report work/validation/backup-final.json
```

默认 Restic 仓库：

`C:\Users\ExampleUser\Documents\ResearchAssetHubBackups`

`verified` 表示备份记录的快照存在且存储完整性检查通过；完整检查读取该仓库的全部数据，并在结束时再次确认快照存在。它没有执行数据库恢复演练，也仍是同机副本。重要资料应另增加外置硬盘、NAS 或云端备份。

## 14. 故障排查

### 网站打不开

```powershell
./scripts/hub.ps1 status
./scripts/hub.ps1 stop
./scripts/hub.ps1 start
```

生产前端缺失时：

```powershell
pnpm --filter @research-asset-hub/web build
./scripts/hub.ps1 start
```

### 搜索没有结果

- 清除高级筛选；
- 切换混合模式；
- 检查后台任务是否完成；
- 确认已执行正式索引；
- 用完整题名或 DOI 做精确搜索。

### PDF、代码或 HTML 无法打开

- 查看按钮是否灰色；
- 检查资产网关健康：<http://127.0.0.1:8766/health>；
- 检查表示是否为 `missing`；
- 对 HTML 通过命令行运行 `scripts/audit_html.py`，再打开 `work/validation/` 中的报告查看缺失依赖；详情页没有审计报告入口；
- 外部 URL 需要本机网络。

如果领域统一页面显示异常，先确认 `/api/v1/domains/<slug>/portal` 是否返回 `renderer: v2`、9 个 `sections` 且 `stale: false`。再用“原始 HTML”核对来源内容；不要为修统一页面而修改来源 HTML。统一页面依赖 API `8767`，原始 HTML 次级入口还依赖网关 `8766`。

### 后台任务一直失败

- 在任务页查看错误；
- 只对已理解原因的任务点击“重试”；
- 缺失源文件要修正 manifest 或明确保持 missing；
- 不要通过删除作业记录隐藏失败。

### 同步冲突

- 比较本地值和外部值；
- 选择保留本地、采用来源或合并；
- 不确定时先保留冲突，不要盲目覆盖。

## 15. 隐私与安全

- 当前全部服务只监听 `127.0.0.1`，没有公开部署。
- 本地 HTML 通过独立网关打开，不能请求任意本机路径；外部 HTML 直链由浏览器直接访问，不受本地网关 sandbox 控制。
- 当前网页没有删除资产按钮；如通过受控 API 删除，后端默认软删除，并且不会删除来源文件。
