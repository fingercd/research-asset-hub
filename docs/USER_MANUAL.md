# Research Asset Hub 用户使用手册

Research Asset Hub 是只在本机运行的科研资料工作台。日常使用主要在网站完成；导入新资料、重建索引、Obsidian/Zotero 同步和备份目前通过命令行完成。

## 1. 启动与进入网站

在 PowerShell 中：

```powershell
cd "D:\ResearchLibrary\research-asset-hub"
./scripts/hub.ps1 start
./scripts/hub.ps1 status
```

打开：

- 网站：<http://127.0.0.1:8765>
- API 文档：<http://127.0.0.1:8767/docs>
- API 健康检查：<http://127.0.0.1:8767/api/health>
- 资产网关健康检查：<http://127.0.0.1:8766/health>

左下角和右上角的状态徽标每 30 秒检查一次：

- **系统就绪**：API 和依赖正常；
- **部分服务不可用**：网站能打开，但搜索、数据库或其他依赖有降级；
- **API 离线**：先检查 `hub.ps1 status`，必要时重新启动。

停止：

```powershell
./scripts/hub.ps1 stop
```

普通停止不会删除数据库和索引。不要手工执行带 `--volumes` 的 Compose 删除命令。

## 2. 全局导航与快捷操作

左侧导航分为：

- 研究：总览、跨领域搜索、领域、关系图谱、论文对比、批注、RAG 问答；
- 系统：后台任务、同步冲突、设置。

在任何页面按 `Ctrl+K`，可搜索题名、作者、DOI/arXiv、仓库、导读或批注。输入后按 Enter 进入跨领域搜索；按 Esc 关闭。资产 UUID 目前不是可靠的全文检索字段，应从已有详情链接进入。macOS 对应 `Cmd+K`。

手机或窄屏使用左上角菜单按钮打开导航。

在论文卡片或详情页点击“加入对比”后，底部出现比较托盘：

- 最多加入 4 篇；
- 点击“打开对比”进入论文对比页；
- 点击关闭按钮可清空当前选择；
- 当前选择保存在浏览器 `localStorage`，普通刷新和路由切换会保留；清理浏览器站点数据后会丢失。

未知地址会进入 `/404` 页面。

## 3. 推荐的日常工作流

### 查找、阅读和记录

1. 按 `Ctrl+K` 输入题名、作者、DOI、arXiv、方法名或代码符号。
2. 在结果卡直接点 PDF、代码、导读或原始 HTML；也可点标题进入详情。
3. 把阅读状态改为“阅读中”。
4. 在详情页添加总结、问题、摘录、评论或一般笔记。
5. 阅读完成后改为“已读”。

以后再次搜索时，卡片会显示你的批注摘要；没有批注显示“无”。

### 比较多篇论文

1. 从搜索结果加入 2–4 篇论文。
2. 打开“论文对比”。
3. 并排查看研究问题、方法、贡献、实验、限制、代码、批注和关系。
4. 保存比较视图，或导出 Markdown。

### 浏览研究脉络

1. 在资产详情切换到“关系”标签，再点击“打开完整图谱/打开关系图谱”。
2. 选择 1–3 跳邻域，观察论文、代码和相关资产。
3. 点击图节点打开资产详情。
4. 已知两个资产 UUID 时，可用“路径”模式寻找连接。

### 向资料库提问

1. 从论文详情点“基于此资产提问”，自动限定该资产；或直接进入 RAG 问答页跨库提问。
2. 提出可以由资料原文回答的问题。
3. 打开答案中的引用，核对引用摘录和原文；页面不保证始终直接显示页码、章节或代码行。
4. 如果显示“资料库证据不足”，不要把它当成否定结论；先检查资料是否已抽取和索引。

## 4. 总览

地址：<http://127.0.0.1:8765/>

可以看到：

- 资产与论文总数；
- 未读、阅读中、已读数量；
- 领域、关系和批注统计；
- 最近资产或继续阅读；
- 从 API 动态生成的全部领域入口，以及每个领域的论文、仓库、研究单元和整体 HTML 可用状态；
- 索引未完成提示或空库引导。

可执行操作：

- 顶部搜索框进入全库搜索；
- 点击资产标题进入详情；
- 直接修改阅读状态；
- 点击领域进入该领域；
- “查看全部”进入搜索；
- 空库引导中的“查看导入任务”可跳到后台任务页。

当前登记了 10 个领域：Agent 学习、AI / 大模型 Infra、世界模型、强化学习、大模型微调、图像与视频生成、大语言模型与大厂技术报告、视觉语言导航（VLN）、游戏强化学习、弱监督视频异常检测（WSVAD）。领域卡不是前端写死的枚举；以后登记并导入新领域后，首页和领域目录会动态出现对应入口。

索引状态提示本身只展示状态和说明，没有跳转按钮。总览数字来自当前数据库，会随着你新增资料而变化；README 中的数字只是注明日期的已验证登记基线。

当前限制：总览没有“导入资料”或“重建索引”按钮；这些操作见 [自行增加知识库指南](USER_KNOWLEDGE_BASE_GUIDE.md)。

## 5. 跨领域搜索

地址：<http://127.0.0.1:8765/search>

### 三种模式

| 模式 | 适合 |
| --- | --- |
| 精确 | DOI、arXiv、完整题名、作者、仓库名和代码符号 |
| 混合 | 默认模式，同时使用关键词、向量和融合排序 |
| 语义 | 不知道准确术语，只能描述研究问题或概念 |

语义模式依赖本地向量索引；没有完成 BGE-M3 索引时可能降级或无结果。

服务刚启动后的第一次混合/语义查询需要把本地 BGE-M3 或重排模型载入显存，可能明显慢于后续查询，甚至需要几十秒。此时可先用“精确”模式查 DOI、题名或代码符号；正式热缓存评测结果见发布报告。

网站会为搜索单独等待最多 120 秒，生产代理默认等待 180 秒；其他普通 API 仍保持 12 秒快速失败。GPU 型混合/语义搜索在本机按顺序执行，避免 RTX 4060 8GB 被并发请求挤爆；精确/关键词模式不等待 GPU 队列。代理阈值可在启动前通过 `HUB_WEB_API_PROXY_TIMEOUT_SECONDS` 调整。

为避免空闲时长期占用内存或显存，搜索模型默认在连续 900 秒没有搜索请求后卸载；下一次混合/语义查询仍会重新加载正式 BGE-M3。可在启动服务前用 `HUB_SEARCH_MODEL_IDLE_SECONDS` 调整秒数，设为 `0` 可禁用空闲卸载。`/api/health` 的 `search_models` 字段可以查看当前 `cold`/`warm` 状态、设备、配置阈值 `idle_seconds` 和实际空闲时长 `idle_for_seconds`；活动请求期间实际空闲时长为 0，读取健康状态不会触发模型加载。

### 筛选

基础筛选：

- 领域；
- 阅读状态：未读、阅读中、已读；
- 类型：论文、代码仓库、数据集。

“更多筛选”：

- 作者或机构；
- 单个标签；
- 起始和结束年份；
- 是否有 PDF；
- 是否有代码；
- 是否有导读；
- 是否有 HTML；
- 是否有批注。

填写高级筛选后点击“应用更多筛选”。“清除更多筛选”只清理高级条件。

### 结果卡

网站默认把论文和已确认的 `implemented_by` 代码仓库合成一个“研究单元”：论文是主卡，仓库关键词命中时仍回到对应论文卡，并标注“命中关联代码”。没有已确认论文关系的仓库继续作为独立仓库卡；把类型切换为“代码仓库”时会查看原始仓库清单。

每张卡可：

- 点标题进入资产详情；
- 修改阅读状态；
- 加入论文对比；
- 按 `PDF / HTML / 导读 / 代码` 的固定顺序快速打开论文文件及关联仓库；
- 查看约 60 字批注摘要；
- 查看相关度分数和领域。

搜索卡上的按钮灰色表示该研究单元没有可用的对应表示；PDF 会进一步区分“来源未提供”和“已登记但文件缺失/来源受限”。按钮上的 `+N` 表示有多个可用入口，展开后可选择具体版本。不可用表示不会发送打开请求。结果较多时点击“加载更多”继续。

搜索无结果时，先切回“混合”，减少筛选条件，再尝试更宽泛的中文或英文关键词。

## 6. 资产详情

地址格式：

`http://127.0.0.1:8765/assets/<asset-id>`

首屏展示题名、作者、年份、venue、领域、标签、阅读状态和快捷打开按钮。

### 概览

- 阅读摘要和结构化元数据；
- 查看已有批注；
- 新增批注；
- 查看全部表示；
- 切换到“关系”标签，再从该标签打开完整图谱；
- 将当前资产带入 RAG 问答。

### PDF

- 使用 PDF.js 在页面内显示；
- 使用“上一页”“下一页”翻页；
- 显示当前页码；
- 已成功取得 PDF 地址但页面解析/嵌入失败时，可“在新窗口打开”；安全会话创建失败时没有该回退按钮。

当前 PDF 面板没有全文搜索、缩放或下载工具栏；需要这些能力时在新窗口用浏览器/PDF 阅读器打开。

### 代码

- 本地代码或 Notebook 在隔离查看区域打开；
- 外部仓库 URL 在新标签页打开；
- 平台不会执行仓库中的代码。

如果你希望在编辑器中运行代码，应从登记的本地目录自行打开，并先审查安全性。

### 导读

- Markdown 使用安全渲染；
- HTML 导读通过隔离资产网关打开；
- Markdown 内容加载或渲染失败时通常回退到 iframe；安全会话创建失败时只显示错误。

### 关系

- 显示邻居数和关系边；
- 可以进入完整图谱；
- 关系真源来自 PostgreSQL。

### 相似论文

- 打开标签后才加载；
- 依赖向量索引；
- 点击结果进入对应详情。

### 原始 HTML

原页面不会被重写。本地 HTML 通过独立 `127.0.0.1:8766` origin 打开，并按登记策略限制脚本、联网和资源访问；只登记了外部 URL 的 HTML 会直接在外部网站新标签打开，不经过本地网关。

- 静态：适合纯展示页面；
- 可信本地交互：允许经过审计的本地脚本；
- 需要联网：明确提示外部依赖。

旧页面缺少本地 JS、CSS 或图片时可能不完整；需要通过 `scripts/audit_html.py` 生成的 CLI 报告确认缺失依赖。

### 批注

可选择：

- 评论；
- 总结；
- 问题；
- 摘录；
- 一般笔记。

标题可选，正文必填并支持 Markdown。提交后会刷新当前资产的批注。

当前详情页不提供资产创建、删除或字段来源 override 的图形按钮；相关后端能力通过 API/正式导入使用。

快捷按钮以及 PDF、代码、导读、原始 HTML 标签会选择该类型的第一个可用表示；“全部表示”列表可以看到其他同类文件，但当前没有用于切换同类表示的选择器。详情批注列表当前只加载 API 返回的第一批数据。

## 7. 领域

领域列表：<http://127.0.0.1:8765/domains>

每个领域显示：

- 名称和 slug；
- 论文、仓库和研究单元数量；
- 阅读进度统计；
- “总览可用”“总览需联网”“总览缺失”或“暂无总览”状态。

点击领域进入 `/domains/<slug>` 后，默认打开“领域总览”标签。当前 10 个领域都已登记整体 HTML；页面通过 `127.0.0.1:8766` 的隔离资产网关把它嵌入 Hub，而不是把来源页面复制或改写进前端。

“领域总览”工具栏可以：

- 在“统一样式”和“原始样式”之间切换；
- 使用“新窗口打开”在独立标签页查看当前样式；
- 查看当前实际应用的是 Hub 统一样式还是来源原始样式。

统一样式只在隔离网关响应中临时应用字体、颜色和基础界面主题，来源 HTML 始终只读；切换原始样式可以核对来源原貌。如果主题无法安全应用，网关会回退或给出提示。若整体 HTML 不可用或会话创建失败，页面会显示错误并回退到原生研究单元目录。

领域详情还有三个标签：

- “研究单元”：完整聚合目录，首批加载 30 个研究单元；点击“加载更多”可继续浏览，页面显示“已加载 X 个研究单元，覆盖 Y / 总资产数”，共享仓库不会重复计数；
- “最近更新”：只展示最近 5 项；
- “统计”：显示全部资产、论文、仓库、研究单元、阅读状态和批注数量。

右上角“浏览或搜索此领域”可在空关键词下直接浏览，也可继续增加关键词和筛选。

领域来自 `config/taxonomy.yaml`、`config/sources.yaml` 和导入数据；页面当前不能创建、重命名或删除领域。

## 8. 关系图谱

地址：<http://127.0.0.1:8765/graph>

### 邻域模式

1. 输入中心资产 UUID，或从资产详情进入。
2. 选择深度 1、2 或 3。
3. 执行查询。

图中可以拖动、缩放并点击节点进入详情。右侧列表也可打开节点。超过约 1,000 个节点时后端可能截断并提示。

### 路径模式

输入起点和终点资产 UUID，查询两者之间的连接路径。

当前页面没有以下控件：

- 共同邻居；
- 按阅读状态过滤；
- 关系新增、编辑或删除。

这些能力若需使用，可通过 API；图形界面当前只提供邻域和路径。

## 9. 论文对比

地址：<http://127.0.0.1:8765/compare>

使用方法：

1. 从搜索/详情加入论文，或在本页搜索论文。
2. 选择 2–4 篇。
3. 点击“保存并生成对比”。
4. 查看并排表格。

比较字段包括：

- 标题、作者、年份、venue；
- 研究问题；
- 方法/机制；
- 主要贡献；
- 实验；
- 限制；
- 代码；
- 个人批注；
- 关系；
- 领域和标签。

缺少的字段显示“无”，不会由 AI 自动臆造。

“导出 Markdown”会由浏览器下载本地 `.md` 文件。“已保存比较”可以重新打开。当前没有删除或编辑已保存比较的按钮。

已保存比较列表当前只加载 API 返回的第一页。

## 10. 批注中心

地址：<http://127.0.0.1:8765/annotations>

可以：

- 按标题、摘要、正文或资产 UUID 在当前列表中筛选；
- 打开批注对应的资产；
- 编辑标题和正文；
- 保存或取消编辑；
- 删除批注；
- 新建批注。

全局新建需要手工填写资产 UUID。更方便的方法是在资产详情页直接添加，系统会自动绑定资产。

更新使用版本校验；如果其他页面已经修改同一批注，保存可能提示版本冲突，刷新后再处理。

当前页面只加载 API 返回的第一批批注，没有无限分页。

## 11. RAG 问答

地址：<http://127.0.0.1:8765/chat>

可以：

- 输入自由问题；
- 使用页面预设问题；
- 按 `Ctrl+Enter` 或 `Cmd+Enter` 发送；
- 从资产详情带入单资产范围；
- 清除单资产限定，改为跨库问答；
- 点击引用返回资产详情或原表示。

系统先在本地检索，再只把回答需要的少量片段发给 DeepSeek。每个事实性回答都应带可打开引用；引用无效时，模型输出会被丢弃。

以下情况会停止生成：

- 没有 DeepSeek 密钥；
- 单次、每日或每月预算超限；
- 模型价格未知；
- 网络超时、限流或服务错误；
- 资料库证据不足；
- 引用锚点无效。

后端会保留检索状态，但当前页面只展示回答和可用引用，不会列出完整的 retrieval-only 证据清单。当前问答会话仅保存在页面内存，刷新或离开后不会显示历史；前端目前不是逐 token 流式展示。

## 12. 后台任务

地址：<http://127.0.0.1:8765/jobs>

显示：

- 等待中、运行中、成功、失败、取消；
- 进度和时间；
- API 返回的任务错误信息。

有进行中任务时约每 5 秒刷新，否则约每 20 秒刷新。也可手动点击“刷新”。

可操作：

- 失败任务：重试；
- 等待中或运行中任务：取消。

当前页面不能创建导入、抽取或索引任务。新增任务由命令行、API 或同步流程创建。

任务列表当前只加载 API 返回的第一页。

## 13. 同步冲突

地址：<http://127.0.0.1:8765/conflicts>

Obsidian 等外部同步发生同字段冲突或“删除对编辑”时，冲突会出现在这里。页面展示 Hub 值和外部值，可选择：

- 保留本地；
- 采用来源；
- 合并。

处理结果会被审计，不会直接改写只读来源目录。当前没有批量解决或“重新同步”按钮；同步仍通过命令行执行。

冲突列表当前只加载 API 返回的第一页。

## 14. 设置

地址：<http://127.0.0.1:8765/settings>

页面只读展示：

- 应用与端口；
- 搜索和向量模型；
- RAG 预算与 provider；
- 来源适配器、状态和只读属性；
- Obsidian/Zotero 等集成状态。

secret、token、password、API key 和 credential 等敏感字段会被脱敏。当前没有保存按钮；配置修改需使用本地配置文件、Windows Credential Manager、环境变量或 API。

## 16. 故障排查

### 网站打不开

```powershell
./scripts/hub.ps1 status
./scripts/hub.ps1 stop
./scripts/hub.ps1 start
```

生产前端缺失时：

```powershell
pnpm --filter @research-asset-hub/web build
./scripts/hub.ps1 start
```

### 搜索没有结果

- 清除高级筛选；
- 切换混合模式；
- 检查后台任务是否完成；
- 确认已执行正式索引；
- 用完整题名或 DOI 做精确搜索。

### PDF、代码或 HTML 无法打开

- 查看按钮是否灰色；
- 检查资产网关健康：<http://127.0.0.1:8766/health>；
- 检查表示是否为 `missing`；
- 对 HTML 通过命令行运行 `scripts/audit_html.py`，再打开 `work/validation/` 中的报告查看缺失依赖；详情页没有审计报告入口；
- 外部 URL 需要本机网络。

如果只有领域整体 HTML 的统一样式显示异常，先切换“原始样式”核对来源页面。原始样式正常而统一样式异常时，不要修改来源 HTML；应保留原始样式退路并检查网关主题应用。两种样式都打不开时，再检查 API `8767`、网关 `8766` 和该领域的总览状态。

### RAG 无法回答

- 先确认普通搜索能找到相关正文；
- 确认 DeepSeek 凭据存在于 Windows Credential Manager；
- 查看预算是否达到上限；
- 打开引用检查正文是否真的包含所问信息。

### 后台任务一直失败

- 在任务页查看错误；
- 只对已理解原因的任务点击“重试”；
- 缺失源文件要修正 manifest 或明确保持 missing；
- 不要通过删除作业记录隐藏失败。

### 同步冲突

- 比较本地值和外部值；
- 选择保留本地、采用来源或合并；
- 不确定时先保留冲突，不要盲目覆盖。

## 17. 隐私与安全

- 当前全部服务只监听 `127.0.0.1`，没有公开部署。
- DeepSeek 密钥只应保存在 Windows Credential Manager。
- 本地 HTML 通过独立网关打开，不能请求任意本机路径；外部 HTML 直链由浏览器直接访问，不受本地网关 sandbox 控制。
- 当前网页没有删除资产按钮；如通过受控 API 删除，后端默认软删除，并且不会删除来源文件。
- DeepSeek 只接收回答所需的少量检索片段，不上传完整资料库。
- 对任何 AI 回答都应打开引用核验，尤其是准备写入论文或公开材料时。
