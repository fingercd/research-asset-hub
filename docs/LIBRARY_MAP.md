# 资料地图：应用源码与用户资料分开

[返回首页](../README.md) · [使用手册](USER_MANUAL.md) · [MCP 接入](MCP_USER_GUIDE.md)

## 三个独立的存储位置

**公共源码包含完整应用，不包含任何人的个人资料库。** 应用目录、用户数据目录和外部资料目录可以位于不同位置；下面仅为示例，实际位置以用户设置和运行配置为准。

```text
D:/ResearchWorkspace/
├─ research-asset-hub/       # 应用源码、文档、测试和空库配置
├─ ResearchLibrary/         # 用户选择的数据目录：数据库、配置和托管资料
├─ ExternalPapers/          # 用户登记的既有 PDF/代码等只读资料
└─ ResearchLibraryBackups/  # 独立备份，不提交到 Git
```

公共网站的资料目录、应用的本地资料库和某一台电脑的实际文件覆盖范围不能混为一谈。目录里的外链不是再分发授权，也不意味着安装包附带论文、权重、数据集或完整第三方代码。

## 从领域找到资料

新安装从空库开始。在界面建立领域并添加论文；精选领域门户可以后补，不是创建领域的前提。查找已经入库的资料时，可按题名、摘要关键词、年份和会议筛选。

使用 MCP 列出完整领域时，先调用 `library_status()` 获取实际领域，再以 `search_assets(query="", domain="…", asset_type="paper")` 逐页检索，核对返回总数与去重数量。静态网站和历史截图不替代当前资料库状态。

## 核实论文和实现

拿到资产 ID 后读取原文页码证据，区分原文、导读和自动抽取结果。核对任务、数据集、实验协议、指标及局限；搜索命中或会议字段不能单独证明论文结论。

论文与实现通过显式关系关联。浏览代码时区分官方/第三方、在线/本地、具体版本及许可证。运行实验应另建工作目录，不能在冻结的来源原件中安装依赖或写入结果。

## 新增和更正

- 日常单篇添加：标题与 PDF 必填，HTML、代码和简介选填。
- 既有永久资料：按[入库指南](USER_KNOWLEDGE_BASE_GUIDE.md)新建旁车来源，原文件原位只读。
- 错误资料：创建独立更正来源，保留原始声明和哈希，不覆盖旧 PDF 或改写冻结 manifest。
- 新领域：名称必填，精选门户和阅读路线可以后补。

来源身份、表示和关系受[来源契约](architecture/source-boundaries.md)约束；开发与验证见[开发指南](DEVELOPMENT.md)。
